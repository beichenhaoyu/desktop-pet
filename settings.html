从 Petdex 公开画廊安装

正在读取已安装形象…

    形象全部来自 Petdex 公开画廊：输入画廊里的名字（例如 deepseek）即下载图集并立即换装， 宠物不必重启。默认形象 deepseek 在首次启动时自动安装。 本项目仅供学习与自娱自乐，仓库不内置、也不再分发任何美术文件。

    唤出插件页的全局快捷键

    正在读取…

    写法：Ctrl / Alt / Shift / Win 加一个主键， 例如 Ctrl+Alt+P、Alt+F12。必须带修饰键，避免劫持普通输入。 换键时先注册新键，成功才注销旧键；被别的应用占了会直接报错并保留原键。

    开机自动运行

    正在读取…

    开关写的是当前 desktop-pet.exe 在 HKCU 的 Run 项，只影响你自己的账户， 不需要管理员权限。关掉即删除该键值。

    Agent 事件接入

    正在读取状态…

    安装会往 ~/.qoder/settings.json 与 ~/.qoder-cn/settings.json 追加本宠物的 hook 条目（首次改动会留 .pre-pet-backup 备份），只增删自己的条目，不动其他 hook。 装好后 Agent 的工具调用、等待确认、任务完成等事件就会驱动宠物。

    游戏模式

    隐身只收起宠物窗：动画、点击穿透轮询与自言自语一并停掉，插件的功能（蓝牙、事件、存储）照常运行。 关掉这个开关就不再轮询前台窗口。

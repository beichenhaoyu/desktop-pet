# 会话可见性从 overlay 卡片迁到本体气泡

agent 桥原来用 `ctx.overlay.show({placement:"above-pet", height:104})` 贴一张状态卡在宠物头顶。
我们决定移除这张卡（连带收回 agent 桥的 `overlay` 权限），改为本体气泡承担两种显示：**常驻状态行**
（状态 + 工具名 + 步数，随事件刷新，不定时消失）与**节点台词**（`needs_input`/`completed`/`failed` 一句话，3.6 秒收起，不覆盖常驻行）。
常驻状态行存在时，宿主自己的随机台词（`src/pet/dialogue.ts`）让路。

**为什么算决策**：`say()` 现在是"压掉换行、截 200 字、3600ms 自动消失"的一次性模型，
气泡宽度又被 `--pet-size`（立绘 266px）和不可 resize 的 360×360 宠物窗锁死 ——
加 sticky 就是给本体新增一种显示状态，而不是给插件多一个参数。选了"常驻 + 台词两层"而不是"只播报节点"
（零本体改动但跑久了头顶是空的）或"多行常驻"（信息最全但会挡住立绘，且要先动气泡尺寸上限）。

**后果**：`overlay` 的 above-pet 跟随与游戏模式压制机制在气泡路径上不存在 —— 气泡随宠物窗整体隐藏，
这条恰好更简单；但点击穿透按立绘范围判定，气泡区域不算 inside，验收时要单独盯一条"悬停气泡不挡鼠标"。

## 修订（2026-10-12，依 T04 几何取证）

上面「节点台词……**不覆盖常驻行**」这句按当前窗口尺寸**做不到**，口径改为：**常驻行与台词共用一个气泡槽，
台词优先占用，3.6 秒收起后常驻行回位**（台词存在期间常驻行只是被临时替换，不是被清除）。

证据（逐格算术在派单工作区 `.dispatch/A股盯盘质量加固/work/T04/bubble-geometry.md`，不入库；下面这几行
就是它的结论，全部由源码常量推出，照着能复跑）：
宠物窗 360×360 且不可 resize，立绘 266 居中（顶边 y=47），`--pet-bubble-bottom` 让气泡底边落在 y=55，
行盒 12px×1.6=19.2、上下内边距 16 —— 1 行顶边 19.8、2 行 0.6、**3 行 −18.6（被裁）**、4 行 −37.8。
所以槽内同时放「常驻 1 行 + 台词 1 行 = 2 行」已是容量极限（只剩 0.6px 余量），而常驻行内容是
「状态 + 工具名 + 步数」、台词最长内置 25 字本身就是 2 行，两者相加必然 3 行起裁。

被这条几何事实一并否掉的三条路（都不进 B3）：
- **加高窗口到 420**：3 行顶边 11.4px 可用，但要改 `src-tauri/tauri.conf.json:17-18`，连带 32 处代码位置
  （T04 表②的 A 列），屏幕上角色整体上移 30px、above-pet 悬浮卡与头顶间距 55→85px —— 属于"重新决定宠物占多大地方"，
  不是气泡分层，且 B3 的边界禁止动 `src-tauri/`。
- **缩字号到 10px/行高 1.25**：3 行顶边 1.5px 勉强不裁，但可读性下降，且 B3 明确不做「改字号配色动画」。
- **放宽 `max-width`**：只减少行数不解决垂直溢出，且直接推翻 `4a7a05d` 立的「气泡永远不超出立绘宽」断言
  （`scripts/verify-isolation.mjs:514`）。

因此 B3 的常驻行按**至多 1 行**验收，且判据是渲染态几何而不是字数：CSS 保证单行（`nowrap` + 省略号或 `line-clamp: 1`），
断言读 `getBoundingClientRect()` 要求 `top >= 0` 且高度 ≤ 单行行盒。字数上限 20 只是输入侧的约束 ——
T04 明确交代「每行 20 字」是按全角宽推算的，真字体折行差 1 字就会退回被裁，所以**不许拿字数当不裁切的证据**。

## 修订（2026-10-16，依 ADR-0010）

上面「移除这张卡（连带收回 agent 桥的 `overlay` 权限）」这条路被 ADR-0010 走得**更彻底**了：
`placement` 的「宠物头顶」那一档不是只给 agent 桥关掉，而是从宿主整体删除
（`PLACEMENT_ABOVE_PET`、`resolve_placement` 的对应分支、`start_follow_timer` 的跟随段一并去掉，`134dfce`）。
所以本文里两处依赖它的表述现在这样读：

- 第 3 行「agent 桥原来用 `above-pet` 贴一张状态卡」—— 仍成立，但**现在它落不回头顶了**：
  过渡期宿主接受 `placement` 而忽略并记一条宿主告警，那张卡现在漂在桌面 `(24,24)`。
  **别把"现在它在左上角"读成 B3 已完成** —— 卡片本体仍在，移除动作归 B3（ADR-0010 决策 6 把它并进 B3）。
- 第 13 行「above-pet 跟随与游戏模式压制机制在气泡路径上不存在」—— 这句的**对照物已整体不存在**了，
  因此气泡路径"少一套要维护的跟随机制"这个论据比原文写的更强。
- 第 30 行被否掉的「加高窗口到 420」那条里"above-pet 悬浮卡与头顶间距 55→85px"这一项已随之失效，
  但它当时的推理（属于"重新决定宠物占多大地方"，不是气泡分层）仍然成立，结论不变。

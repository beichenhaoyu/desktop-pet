# 宠物立绘素材来源

`whale/*.webp` 来自开源项目 **dsh-whale-musume**（鲸鱼娘），
原作者：Sutera-Diffusus，协议：MIT。
仓库：https://github.com/Sutera-Diffusus/dsh-whale-musume

本目录文件为原项目 `assets/generated/dsh-whale-state-*.webp` 的重命名子集：

|---|---|---|
| idle.webp | dsh-whale-state-idle-cute.webp | 待机 |
| greet.webp | dsh-whale-state-greet.webp | 启动打招呼 |
| sleep.webp | dsh-whale-state-sleep.webp | 睡觉 |
| run.webp | dsh-whale-state-running.webp | 踱步 |
| react-wink.webp | dsh-whale-state-wink.webp | 反应·眨眼 |
| react-blush.webp | dsh-whale-state-blush.webp | 反应·脸红 |
| react-celebrate.webp | dsh-whale-state-celebrate.webp | 反应·庆祝 |
| react-shock.webp | dsh-whale-state-meme-shock.webp | 反应·震惊 |
| curious.webp | dsh-whale-state-curious.webp | 好奇（随机小动作） |
| teasing.webp | dsh-whale-state-teasing.webp | 摸头反应 |
| angry.webp | dsh-whale-state-angry.webp | 拉尾巴反应 |
| night.webp | dsh-whale-state-night.webp | 深夜待机（22:00-7:00） |
